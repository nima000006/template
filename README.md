# Nexus Pro — نکسوس پرو

**Premium AI SaaS Dashboard Template | RTL + LTR | Next.js 15 + TypeScript**

> The first RTL-ready AI SaaS dashboard with Shadcn/UI. Built for Persian and international developers.

## Stack

| Technology | Purpose |
|---|---|
| Next.js App Router | Framework + SSR |
| TypeScript strict | Type safety |
| Tailwind CSS v4 | Styling + theme system |
| next-intl | i18n (Persian + English) |
| Recharts | Interactive charts |
| React Hook Form + Zod | Form validation |
| Framer Motion | Animations |
| Lucide React | Icons |

## Features

- ✅ True RTL + LTR (Tailwind logical properties)
- ✅ Bilingual Persian + English, runtime switchable
- ✅ 5 Color Themes + Dark/Light Mode
- ✅ 30+ Pages (Marketing + Dashboard)
- ✅ AI Workspace (chat UI, token meter, model selector)
- ✅ TypeScript strict — zero `any`
- ✅ Production ready, zero build errors

## Quick Start

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` → redirects to `/fa` (Persian), or `/en` for English.

## Pages

**Marketing:** Landing, Features, Pricing, FAQ, Contact  
**Auth:** Login, Register  
**Dashboard:** Overview, Analytics, AI Workspace, Billing, Notifications, Support, Settings
